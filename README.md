# Bake Off
By Emma Joa

## Rules and Controls
The game runs in three challenges: Signature, Technical, and Showstopper.
Your goal is to complete the tasks before the time runs out to achieve a high score.
Paul Hollywood and Nigella Lawson will judge your bakes and determine your overall score.
This week's theme is cakes. In future iterations, it will incorporate additional bake-off themes, such as bread and patisserie.


## Set up
All you need to do is download the .py file and run it using Python :) 
Happy baking!
